## Biblioteca

@react-native-google-signin/google-signin

## Instalação

A biblioteca foi instalada utilizando:

npx expo install @react-native-google-signin/google-signin

## Config Plugin

Após a instalação, o Expo adicionou automaticamente o config plugin:

@react-native-google-signin/google-signin

## Motivo da utilização

A biblioteca fornece integração nativa com o Google Sign-In
para aplicações React Native.

## Limitação

A biblioteca utiliza código nativo e, portanto, não pode ser
executada diretamente pelo Expo Go.

Será utilizado um Development Build para executar e testar
a autenticação Google.
